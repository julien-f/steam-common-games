Bundles

Browse current Steam game bundles from IsThereAnyDeal, with the same ratings/HLTB/tags table as the Library Explorer

The Bundles page needs an IsThereAnyDeal API key. Set ITAD_API_KEY in your .env file (register a free key at isthereanydeal.com) and restart the server.

Region: (⚙ Preferences to change)

Prices are shown in whatever currency each store actually charges for that bundle — most stores follow your region preference, but some (e.g. certain Fanatical/Digiphile bundles) only ever price in USD regardless of region.

Not on Steam

Included in this bundle but not resolved to a Steam listing — other-shop-only, DRM-free, or ITAD has no mapping yet.
